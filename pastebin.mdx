# VylarisPaste

VylarisPaste ist ein Ende-zu-Ende verschlüsseltes PasteBin. Dein Text wird im Browser verschlüsselt, bevor er den Server erreicht.

## Was VylarisPaste kann

- Zero-Knowledge: Der Server sieht nur verschlüsselten Text.
- E2E-Verschlüsselung mit 256-bit AES in Galois Counter Mode.
- Selbstlöschung von Minuten bis Wochen.
- Optionaler Passwortschutz für extra Sicherheit.

## Warum VylarisPaste

- Perfekt für sensible Texte und Code-Snippets.
- Inhalte bleiben privat, auch für den Betreiber.
- Basierend auf dem PrivateBin-Prinzip mit minimalistischem Datenschutzfokus.
